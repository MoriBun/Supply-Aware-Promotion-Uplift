# Xanh SM artwork

Retrieved 2026-10-08. Artwork is stored locally so the dashboard does not depend on a remote image host.

- `xanh-sm-white.png`: original white/gold Xanh SM logo used on https://tuyentaixe.xanhsm.com/ngayhoituyendung. Asset URL: https://w.ladicdn.com/s450x350/682b14dd6c648c0012c0d0d5/logo-xanh-sm-trang-20250808051809-ommsz.png
- `favicon.png`: original symbol from https://www.greensm.com/favicon-192x192.png. Used for the favicon, touch icon and compact sidebar. The main Xanh SM website currently redirects to Green SM; the requested Xanh SM name and historical wordmark are retained.

Images are unmodified. Keep their aspect ratios. The full white logo belongs on a dark background; the compact symbol retains its original white background. UI cyan `#2dccd3` and gold `#ffca00` match the SVG logo embedded on https://www.greensm.com/vn-vi. Darker UI colors are dashboard adaptations for text contrast, not an official brand manual. Plus Jakarta Sans is a UI font choice, not a claim about the official brand font.
